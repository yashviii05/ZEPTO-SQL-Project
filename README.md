# ZEPTO-SQL-Project
Overview

Analyzed Zepto’s product and inventory dataset using PostgreSQL to uncover pricing, discount, stock availability, revenue, and inventory trends. The project involved data exploration, cleaning, transformation, and business-oriented SQL analysis.

Dataset

Product-level Zepto dataset containing SKU information, product categories, MRP, discounted selling price, available quantity, weight, stock status, and quantity-related attributes. The dataset was explored for row counts, null values, duplicate product names, categories, and stock availability before analysis.

Key Business Questions Answered
Which products offer the highest discounts?
Which high-value products are currently out of stock?
Which categories generate the highest estimated revenue?
Which expensive products offer relatively low discounts?
Which categories provide the highest average discounts?
Which products offer the best price per gram?
How can products be classified based on weight?
Which categories hold the highest total inventory weight?

Tools Used: PostgreSQL, pgAdmin
